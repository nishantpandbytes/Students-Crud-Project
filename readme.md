# Student Database CRUD Application

A Python backend FastAPI application with SQLite database for managing student records. Developed as part of the EWB Edu Tech Pvt. Ltd. Internship Assignment.

## 📌 Project Features
- **Create**: Add new student records.
- **Read**: Fetch all student records or retrieve specific profiles by ID (with filtering support).
- **Update**: Modify student details (PUT request).
- **Delete**: Remove student records from the database.
- **Validation & Error Handling**: Input schema validation with Pydantic and custom HTTP 404 handling for missing records.

## 🛠️ Prerequisites & Dependencies
- Python 3.8+
- FastAPI
- Uvicorn
- SQLAlchemy
- Pydantic
